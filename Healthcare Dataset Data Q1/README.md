#DESCRIPTION 
The dataset contains administrative, demographic, clinical, and financial records for healthcare patient admissions. Each row represents a individual patient admission event and includes the following 15 attributes:
Patient Demographics: Name, Age, Gender, Blood Type   
Clinical Details: Medical Condition (e.g., Cancer, Diabetes, Obesity), Medication (e.g., Paracetamol, Ibuprofen, Penicillin), Test Results (Normal, Abnormal, Inconclusive)  Administrative Details: Doctor, Hospital, Insurance Provider, Room Number, Admission Type (Urgent, Emergency, Elective), Date of Admission, Discharge Date   
Financial Details: Billing Amount

# WHY SELECTED THIS DATA 
Containing 55,500 records, it directly meets the criteria of a large dataset with 50,000+ rows suitable for robust statistical and data processing tasks

It seamlessly merges financial (Billing Amount), operational (Admission Type, length of stay, Hospital, Doctor), demographic (Age, Gender), and clinical (Medical Condition, Test Results, Medication) attributes. This complexity enables multifaceted analysis across various operational domains

High Business Relevance:  Healthcare providers and health insurance platforms face continuous pressure to optimize resource allocation, manage operational costs, improve patient care outcomes, and prevent revenue leakage or billing anomalies.
